# Transfer++ 🚀

> **High-speed, zero-config local network (LAN) file transfer between PCs.**  
> Transfer files of **any size** (from megabytes to 50GB+) at full Gigabit / Wi-Fi wire speed with no cloud limits, no cables, and no external dependencies.

---

## ✨ Features

- **Any File Size:** Chunked streaming support for huge files (10GB, 50GB, etc.) without RAM bloat.
- **Zero Configuration:** Automatically binds to your local LAN IP and generates a ready-to-use link.
- **Modern Clean UI:** Sleek minimalist dark theme with drag-and-drop, real-time progress bars, and 1-click download.
- **Cross-Platform:** Works seamlessly between Windows, Linux, macOS, and mobile browsers on the same local network.
- **Zero Dependencies:** Built with pure standard Python 3. No `pip install` required.

---

## ⚡ Quick Start

### 1. Launch Transfer++
Double-click `run.bat` or run:
```bash
python transfer.py
```

### 2. Connect from Any PC
Open your web browser on any computer connected to the same Wi-Fi / LAN and enter the address displayed in the console:
```
http://<YOUR-LOCAL-IP>:7777
```

### 3. Drag & Drop
- **To Send:** Drag any file into the upload zone.
- **To Receive:** Click **Descarregar** in the *Ficheiros Recebidos* section. All files are stored safely in `D:\TransferPlusPlus\received\`.
